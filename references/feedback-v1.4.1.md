# V1.4.1 四项反馈修复

四项反馈均已复现，保持产品版本V1.4.1，只更新本地源码与安装包，不提交或上传GitHub。

| 问题 | 原因 | 修复 |
| --- | --- | --- |
| 合盘--brief --comparison报gender未定义 | 精简交叉页没有people，错误落入单人分支 | 关系模式的comparison不进入单人分支；按原argv读完全部交叉证据 |
| 交运之前提前套用大运 | 解读投影只比较start_year/end_year | 以原qiyun起运瞬间为锚，按十公历年交运；目标日沿用输入时区正午；年度页保留实际相交的前后运 |
| 紅鸞无命中 | 简繁映射缺紅／鸞等字及完整术语别名 | 扩展共同归一化与情感术语别名，繁简查询排序一致；正文与出处不改 |
| 非对象options被默认值覆盖 | input.options || {}把false、0、空字符串、null变成{} | 只有未提供时采用默认；显式无效值报错；同样检查双人、时辰和候选输入 |

示例出生2000-01-01，起运2008-03-12 14:00（北京时间）：2008-01-01无当前大运；交运当日正午尚未交运；3月13日为第一运。2018-03-12正午仍第一运，次日第二运。日期口径与新增状态见[岁运说明](romance-method.md)。

专项用例保留在tests/feedback-v1.4.1-hotfix.test.cjs：真实mobile.sh续页（八字／紫微／两者）、全部交叉关系及柱位矩阵还原、旧chart字节不变、可信缓存、交运前后一秒、目标时区、交运年度双运、无目标日期、非法options与繁简排序一致。相关旧回归、解包验收和实际数量记录在releases/v1.4.1/release-validation.json；本轮不默认执行完整回归或全年候选采样。
