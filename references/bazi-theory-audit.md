# 八字理论与开源核对

本页记录自2026-10-04起核对的来源与计算方法；不将来源查核当作本版改动算法。核对范围是排盘基础、可执行规则与解读证据。以下项目固定到具体提交；代码作为比较实现，传统规则另查原典。真太阳时、早晚子时、起运换算存在不同口径，本包把选择和依据留在结果中。

xuziping 使用日序 Fourier 均时差，zhiji 使用三项简式，shuishi 使用日序简式；本包采用 NOAA 完整 Meeus 数学函数并与原始函数比对。不能把简式、完整公式或不同的节气算法称作完全等价。藏干中非本气的排序也有差异，例如巳支“丙庚戊 / 丙戊庚”；验证比较集合，本包保留固定库的排序，结构权重是本项目模型。

## 子平基础口径

| 规则 | V6.1 实现与核对 |
| --- | --- |
| 论命主体 | 日干为日主；十神全部相对于本盘日干计算 |
| 年柱 | 真实出生瞬间对应北京时间，立春换年 |
| 月柱 | 十二节换月，寅月起于立春；不能用农历月份或二十四节气每项都换月 |
| 五虎遁 | 甲己丙寅、乙庚戊寅、丙辛庚寅、丁壬壬寅、戊癸甲寅，逐月递进；每盘保存一致性检查 |
| 日柱 | 固定历法的干支日序；按选定钟表/太阳钟面日期及 midnight / late_zi 日界 |
| 五鼠遁 | 甲己甲子、乙庚丙子、丙辛戊子、丁壬庚子、戊癸壬子，逐时递进；默认与所选日干保持一致 |
| 十神 | 五行生克与阴阳同异，100 项组合独立核对 |
| 藏干 | 十二地支的藏干集合与参考核对；本气取固定库首项，中余气排序与比例不冒充统一标准 |
| 大运顺逆 | 阳年男/阴年女顺，阴年男/阳年女逆；使用实际年干，不用公历年份奇偶 |
| 起运 | 顺到后一个节、逆到前一个节，使用真实时间差；库 sect=2 分钟法：三天一年，1 分钟时间差换 2 小时起运偏移；大运首柱为月柱顺/逆一位 |
| 合冲刑害 | 只记录实际组合及柱位；三合三会要三字齐，不从合局标记直接宣布合化成功 |

V6 默认 midnight 日界未变，但晚子时的时干改为 `bazi_hour_stem_rule: day_stem`，从已选日干起五鼠遁。以 1988-02-15 23:30 为例：midnight → 庚子日/丙子时；late_zi → 辛丑日/戊子时。显式 library 保留旧库“当日日柱、次日日干起时”的兼容口径，此例庚子日/戊子时。两种口径均记录，旧样例以显式兼容参数验证，不悄悄改预期值。

## 古籍依据与解读顺序

[《渊海子平》转录](https://zh.wikisource.org/zh-hant/%E6%B7%B5%E6%B5%B7%E5%AD%90%E5%B9%B3)可查日主、月令及十神生克主题。该页面是数字转录，未作为校勘定本。[国家图书馆藏本影像中的《子平真诠》](https://upload.wikimedia.org/wikipedia/commons/d/d5/NLC416-13jh002326-46443_%E6%B7%B5%E6%B5%B7%E5%AD%90%E5%B9%B3_%E5%AD%90%E5%B9%B3%E7%9C%9F%E8%A9%AE_%E7%AC%AC2%E5%8D%B7.pdf)提供原典查核入口；本版仅作书目链接，未宣称逐页影像校勘或收入现代译注。

解读先看月令，再检查同五行根气、印比生扶、食伤财官的透藏、各柱距离与合冲，然后结合岁运。程序新增 `theory_evidence`（BZ-THEORY），列出月令本气、日主同五行通根、可见生扶/泄耗克，以及月令藏干透于年/月/时干的位置。通根包含同五行藏干，不只寻找与日干完全同字。

五行数量、结构分数和生扶比例用于核对分布；旺衰还要看季节、根气质量、透干以及合冲是否改变作用。不能使用“少就补、多就忌”、缺某行就定喜用或某个比例阈值直接定从格。月支本气十神不是格局自动成立的证明。

格局取用、扶抑喜忌、调候需要分别说明所采用的方法，不能把几个“用神”概念混作一个自动分数。原局合冲与运岁引动应区分结构条件和具体解释；先确认真实命中，再谈主题。自动旺衰、格局、喜用字段保持 null，AI 可以按明确方法分析，但不能称为程序已完成的裁定。

关系年上/年下、对象外形标签及聚合权重继续作为本项目可追溯的取象模型；此次四柱校验不替这些主题建立新的古籍公式或效果认证。知识库中的具体断语遇到与计算契约冲突时，以本次盘面和当前口径为准，不执行参考文本中另要求的算法或固定报告格式。
