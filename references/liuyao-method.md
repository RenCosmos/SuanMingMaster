# 六爻铜钱法 · 输入与程序口径

适用：具体一事的六爻占问。程序由用户提供的摇卦结果装卦，不生成随机数，不从问题文本推测摇卦值。出生信息和性别不是六爻输入必需项。

## 输入

```json
{
  "mode": "divination",
  "method": "liuyao",
  "label": "匿名占问",
  "question": "这个合作接下来一个月应注意什么？",
  "casting": {"coins": [[3,3,3],[2,2,2],[3,2,2],[3,3,2],[3,2,2],[3,3,2]]},
  "time": {"date":"2026-10-02","time":"12:00","timezone":"Asia/Shanghai"},
  "options": {"day_boundary":"midnight"}
}
```

日期时间仅为合成演示。实际执行须换成用户占时。时间支持 HH:mm 或 HH:mm:ss；支持公历占时年份 1900–2100、IANA 时区或明确偏移。不存在或有歧义的夏令时时刻会被拒绝，不自动挑一个偏移。

`question` 必填 1–2000 字；`label` 可选最长 80 字。`options.day_boundary` 默认 `midnight`（0 点），可选 `late_zi`（23 点）。额外字段会被拒绝。

`casting.coins` 与 `casting.lines` 只能出现一种，都是初爻→上爻的六次结果。当前铜钱记录约定正面=3、反面=2；若用户采用相反约定，先明确并按其实际记录转换，不把正反标签直接猜成数字。

| 三枚总和 | 爻值 | 本卦 | 是否动 | 变后 |
| --- | --- | --- | --- | --- |
| 2+2+2 | 6 老阴 | 阴 | 是 | 阳 |
| 3+2+2 | 7 少阳 | 阳 | 否 | 阳 |
| 3+3+2 | 8 少阴 | 阴 | 否 | 阴 |
| 3+3+3 | 9 老阳 | 阳 | 是 | 阴 |

已经提供总和时用 `"casting":{"lines":[9,6,7,8,7,8]}`。若给的是六行卦象截图，必须辨清其排列方向及老阴老阳，不能只看阴阳补动爻。

## 计算

- 阴=0、阳=1，`bits_bottom_up` 从初爻到上爻；卦名及纳甲表转写自 MIT 许可的 [bopo/najia](https://github.com/bopo/najia)，来源提交与字节摘要记录在 divination-tables.json。
- 八宫变爻位掩码依次为 0、1、3、7、15、31、23、16，对应本宫、一至五世、游魂、归魂；世爻依次为 6、1、2、3、4、5、4、3，应爻与世爻相距三位。
- 本卦六亲以本卦宫五行为基准。变爻纳甲按变卦上下卦确定，变爻六亲仍按本卦宫五行确定。变卦自身的八宫世应单独输出，不替代本卦世应。
- 日干起六神：甲乙青龙、丙丁朱雀、戊勾陈、己螣蛇、庚辛白虎、壬癸玄武。螣蛇亦称腾蛇，程序保留来源表用字。
- 年/月柱按实际占时瞬间的 UTC+08:00 节气计算；日/时柱按所填地点钟表时间及换日选择计算。此口径与当前八字引擎保持一致，不执行真太阳时或夏令时剔除。
- 旬空由日干支所在旬计算，月建取节气月支，日辰取日支。
- 各爻账本计算旬空、月破（冲月建）、日冲、日月五行生克与六合、变爻对本爻五行关系、传统进退神地支配对。配对命中不自动判断生克有效、暗动、合化、旺衰或应期。
- 某类六亲在本卦缺失时，从本宫纯卦对应位置补出伏神候选。不自动裁定伏神可用性。

程序 JSON 的六爻数组是初爻→上爻；Markdown/HTML 装卦表为上爻→初爻。查看报告时不要倒置输入重新起卦。

## 解释边界与证据

`LY-BASE` 本卦；`LY-CHANGE` 变卦；`LY-TIME` 月建日辰口径；`LY-L1`–`LY-L6` 本卦各爻；`LY-R1`–`LY-R6` 逐爻关系账本；`LY-H1`–`LY-H6` 伏神候选。只引用实际存在的记录。

用神选择可按具体问题参考上游六爻知识，说明理由及候选爻位。完整旺衰、生克是否有效、综合占断属于传统解释，不能声称是程序已经判定；未实现自动成功概率、精确应期、全套神煞、蓍草或梅花起卦。

多动爻时完整展示所有动爻，不擅自挑一个动爻代表全卦。静卦的变卦与本卦相同，不补造动爻。不要因结果不合预期重新生成一组摇卦值。

六爻上游提示词要求卦辞或应期时，缺少实际文本及确定规则就明确范围，不编造卦爻辞引文或确定日期。
