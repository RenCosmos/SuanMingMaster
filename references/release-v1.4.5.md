# V1.4.5 本地发布

完善本次对话核验发现的三处细节，不改八字／紫微计算、原始命盘schema、规则或旧报告。本版仅本地保存，不提交、推送或上传GitHub；旧V1.4.4发布物不修改。

- 年度情感增量页新增partner_stars_visible与partner_stars_hidden，保留兼容摘要partner_stars和原始流年全部证据；显干、藏干各有来源字段及下标，防止把藏乙正财说成透干。
- 新增按需--page ten-gods，将natal与current_dayun分层列示显干／藏干。当前运仍按原精确交运瞬间选择，未知时辰按已计算候选归组并保留交运范围，不把原局比肩等归到当前大运。
- 新增--reuse SELF/chart.json --pair-with OTHER/chart.json --out PAIR_TASK，桥接两个已保存且核验的单人／时辰对照结果，调用原固定关系表返回稳定柱交叉矩阵、双向投射及关系。完整合盘入口保留；桥接明确full_pair=false，变化柱与未算紫微不夹带，分页按pair_key绑定完整argv。

普通异性缘仍一次overview，不默认加分层页或高级检索；只有归属问题或时辰未知的双人问题才读新契约。双方源chart/context/validation不改写，已有可信回执复用；外部结果缺回执时只核验一次，再复用独立交叉回执。20/12/28KiB容量保护、缓存、全部候选采样、107主题及435份计算依赖保留。

专项与完整发布验收分别记录，见根目录验证记录及本版本发布回执；桌面／解包验收不冒称手机实测。缺Node仍按标准安装说明单独联网准备，不生成离线包。
