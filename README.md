# 算命大师（SuanMingMaster）

面向 **RikkaHub 2.5.6** 的程序排盘与民俗知识技能，最新版 **V1.1.5**。

## 下载与安装

1. 下载 [完整安装包](bazi-ziwei-rikkahub-v1.1.5.zip?raw=1)，在 RikkaHub「技能 / Skills」中从文件导入，启用 `bazi-ziwei`。
2. 将助手系统提示词替换为 [RikkaHub系统提示词.txt](RikkaHub系统提示词.txt)。
3. 绑定 Linux Workspace，准备 Node.js 20+，执行自检；具体步骤见 [INSTALL.md](INSTALL.md)。

完整程序源码、计算依赖、67 个知识主题、方法文档、合成输入和来源许可，都包含在安装包的 `bazi-ziwei/` 目录中。解压即可查看和修改源码。手机导入时直接使用完整 ZIP。

## 功能

- 八字、紫微斗数与岁运：程序排盘、真太阳时验证、逐年及大运合冲关系、宫干飞化。
- 婚恋：单人预测、双人合盘、对象画像、有原典出处的单人年上／年下取象。
- 出生时间不确定：全天、时间范围或候选时分对照。
- 六爻：根据用户提供的六次铜钱结果排本卦与变卦。
- 疏文／表文：祈福、祭祖、祭亡、还愿、忏悔、求财与通用呈告；文言或白话，公历／农历日期，按需导出 TXT 和横排／竖排 HTML。
- 67 个可检索知识主题，包含术数方法、传统民俗、修行文献及来源卡；原有 66 个主题完整保留。

默认在聊天中回答，用户需要时才导出报告或疏文。知识检索直接传参；输入优先 stdin，显式临时输入在使用后自动清理。源码、提示词、知识库和随包示例不存放用户的个人资料。

可直接说：“帮我写一份祭祖表文。”无需先排盘；给出落款姓名、对象称呼、使用日期和想表达的心意，有地方范本可一并提供。
